Fundamento Teórico

Método de Interpolación de Lagrange

📐

Definición

Dado un conjunto de \(n+1\) puntos \((x_0, y_0), (x_1, y_1), \dots, (x_n, y_n)\), el polinomio de interpolación de Lagrange construye un polinomio de grado \(n\) que pasa exactamente por todos los puntos.

🧮

Fórmula General

\[P(x) = \sum_{i=0}^{n} y_i \cdot L_i(x)\]
📏

Polinomios Base

\[L_i(x) = \prod_{\substack{0 \le j \le n \\ j \neq i}} \frac{x - x_j}{x_i - x_j}\]
✅

Propiedad Clave

Cada \(L_i(x)\) cumple que \(L_i(x_i) = 1\) y \(L_i(x_j) = 0\) para \(j \neq i\). Esto garantiza que el polinomio toma exactamente el valor \(y_i\) en cada punto \(x_i\).

Ejercicio 1

Temperatura de Ebullición del Agua en La Paz, Bolivia

¿A qué temperatura hierve el agua en El Alto, el Centro y la Zona Sur?

🏔️

Contexto del Problema

La ciudad de La Paz, Bolivia, presenta una geografía única con grandes variaciones de altitud. El punto de ebullición del agua disminuye conforme aumenta la altitud, ya que la presión atmosférica es menor. Usando datos de referencia (tabla del problema 21), aplicaremos la Interpolación de Lagrange para estimar la temperatura de ebullición en tres zonas de La Paz. Las altitudes se convierten a pies (ft) para coincidir con la tabla de datos.

🏔️

El Alto

4,050 m.s.n.m.
≈ 13,287 ft · Meseta altiplánica
🏛️

Centro

3,640 m.s.n.m.
≈ 11,942 ft · Plaza Murillo
🌿

Zona Sur

3,020 m.s.n.m.
≈ 9,908 ft · Valle bajo de La Paz

Ciencia de Datos & Desarrollo de Software

Interpolación aplicada a la predicción del rendimiento de un pipeline de ML en producción

💡

Planteamiento del Problema

Un equipo de ingeniería de software y ciencia de datos está desarrollando un sistema de machine learning en producción (MLOps). El sistema procesa datos en tiempo real y genera predicciones. El equipo ha medido el throughput (solicitudes procesadas por segundo) del pipeline de ML según la cantidad de features (características) que el modelo procesa por cada solicitud.

A medida que se agregan más features al modelo, aumenta la complejidad computacional, lo que reduce el throughput. El equipo necesita estimar el throughput cuando el modelo usa 35 features y 55 features para planificar la infraestructura de servidores.

Pregunta: ¿Cuál será el throughput del pipeline de ML cuando el modelo procese 35 y 55 features, usando interpolación de Lagrange?
